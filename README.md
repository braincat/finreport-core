# FinReport-Core MVP v1.0

純規則報表正規化與合併引擎。**零雲端呼叫、零 LLM、可完全離線執行**，資料不離開客戶端電腦。
為金融／保險行政報表自動化設計，主打「資料不出門、數字零容錯、不動現有 IT 架構」。

## 為什麼是純規則而不是 AI

金融與保險業的資安審查會問一句話：資料會不會上傳雲端。只要架構裡有任何一個 LLM API 呼叫，
這個案子就必須走資安審查、簽 DPA、做 PII 評估。本引擎把這些全部拿掉：
金額、日期、主鍵、借貸平衡全是可歸責的確定性規則，錯誤時停止並留下稽核紀錄，不會「猜」。

## 快速開始

```bash
pip install openpyxl
python3 tools/make_demo_data.py                       # 產生去識別化測試資料
python3 -m finreport.cli --config config/demo_config.json --audit output/Audit_Error_Log.csv
python3 tests/test_acceptance.py                      # 18 項驗收
```

## 驗收指標（實測）

| 指標 | 標準 | 實測 |
|---|---|---|
| 執行時間 | 1,000 筆 ≤ 15 秒 | 0.02 秒 |
| 計算正確率 | 100% | 100.00%（8 欄位 × 1,000 列，0 不符） |
| 異常阻斷 | 缺主鍵／金額非數值／主鍵重複 → 停止並產出稽核 | 三類皆通過，且不產出正式報表 |
| 離線執行 | 斷網可跑通 | 封鎖 socket 後完整通過 |

## 架構

```
config/*.json        客戶配置層（Tier 2）：欄位對應、型別、輸出樣板
finreport/normalize.py   金額／日期／文字正規化規則
finreport/schema.py      設定檔驗證
finreport/engine.py      讀取 → 正規化 → 主鍵合併 → 阻斷式稽核 → 輸出
finreport/cli.py         命令列入口
tools/make_demo_data.py  去識別化測試資料產生器（含獨立期望值）
tests/test_acceptance.py 18 項驗收測試
```

## 稽核代碼

| 代碼 | 意義 | 等級 |
|---|---|---|
| A01 | 主鍵／對應鍵空白 | 阻斷 |
| A02 | 主鍵或對應鍵重複 | 阻斷 |
| A03 | 金額或數值欄位非數值 | 阻斷 |
| A04 | 必要欄位空白 | 阻斷 |
| A05 | 日期無法解析 | 阻斷 |
| A07 | 對方報表查無此對應鍵 | 警告 |
| A08 | 借貸不平衡 | 警告（可設為阻斷） |

阻斷成立的定義：**不產出正式報表**，只產出 `Audit_Error_Log.csv`，讓行政人員修資料後重跑。

## 雙層授權

- **Tier 1**（`finreport/` 引擎、正規化規則、稽核狀態機）：AIArchLab 保留所有權，客戶取得單一專案執行授權。
- **Tier 2**（`config/*.json` 欄位對應、輸出樣板、產出報表）：驗收後產權移轉客戶，客戶可自行調整欄位。

## 支援的格式

- 來源：`.csv`（UTF-8/BOM）、`.xlsx`／`.xlsm`
- 金額：`12,345`、`NT$12,345`、`12345.00`、`（1,200）`（負數）、`1,200-`（負數）、全形數字
- 日期：`2026-10-30`、`2026/10/30`、`20261030`、`10/30/2026`、`2026年10月30日`、民國 `115/10/30`、Excel 日期序號、全形數字
